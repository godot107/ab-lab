# Sample stakeholder briefs (synthetic data)

> **Not real results.** Both briefs below were produced by `analysis/brief.py`
> from traffic generated by `analysis/synthetic_traffic.py` against a local
> copy of the app, with a hand-set true effect of **+12 points** for layout B.
> No real visitors are involved. They show what a stakeholder receives at each
> stage, and that the pipeline recovers a known effect.

Reproduce: run the app locally with `AB_EXPERIMENT=exp001_demo`, send traffic
with `python analysis/synthetic_traffic.py --url http://localhost:5000
--visitors 120 --seed 7` (then 520 more with `--seed 8` for the final), and run
`python analysis/brief.py --db <db> --experiment exp001_demo [--final]`.

Two things to read for:

1. **The mid-test update withholds the comparison.** It has progress, data
   health and pooled usage, but no per-layout rates. That's deliberate:
   `docs/experiment_design.md` section 8.
2. **The exploratory rows in the final brief include noise.** The generator
   gives both layouts *identical* "kept exploring" behaviour, yet the final
   brief shows 42% vs. 60%. That gap is chance, which is why those rows are
   labelled leads for the next experiment, not findings.

## Dashboard layout test: decision brief

*Experiment `exp001_demo` · data Sep 22 to Sep 22, 2026 (0.0 days) · generated Sep 22, 2026 (UTC)*

> **Synthetic demo data.** 640 of 640 visitors were generated by `analysis/synthetic_traffic.py` with a known, hand-set effect. This brief demonstrates the pipeline and the reporting; it is not evidence about real users.

### The question

Does putting the trend chart first, instead of the KPI tiles, get more people to open the breakdown by occupational sector? Opening the breakdown is the measure of whether the dashboard invites a second question. The measure, the sample size and the decision rule were fixed before any data arrived (`docs/experiment_design.md`).

### Bottom line

**Adopt layout B (chart first).** Putting the chart first raised the share of visitors who opened the sector breakdown from 31% to 41%, a gain of 10 points.

### The evidence

|  | Layout A (tiles first) | Layout B (chart first) |
|---|---|---|
| Visitors | 299 | 341 |
| Opened the breakdown | 92 | 139 |
| **Rate** | **30.8%** | **40.8%** |

- **Difference:** +10.0 pts for B. Plausible range, given the sample: +2.6 pts to +17.4 pts.
- **Could it be chance?** If the layouts truly performed the same, a gap this large would show up about 1 time in 116. The bar set in advance was 1 in 20.
- **Sensitivity:** with this many visitors the test reliably detects differences of 11 points or more.

### How far to trust it

- **Traffic split:** 299 / 341 visitors (A / B). Consistent with the planned 50/50.
- **Event integrity:** every click traces back to an exposed visitor.
- **Sample:** 299 visitors in the smaller layout against a plan of 250.
- **Audience:** visitors to a portfolio site, mostly recruiters and peers. The result describes this audience, not every dashboard user.
- **What it measures:** whether people dig into the breakdown, which is engagement, not proof of usefulness. A layout that answers the question faster could lower it.
- **Not checked:** page speed and error rates were not instrumented, so the decision has no guardrail against a layout that is slower or breaks.

### How each layout was used (exploratory)

Context for the decision, not part of it. These cuts were not the test's question, so a difference here is a lead for the next experiment, not a finding.

|  | Layout A | Layout B |
|---|---|---|
| Opened the breakdown | 31% | 41% |
| Median time to first click | 0 s | 0 s |
| Kept exploring (of openers) | 42% | 60% |
| Came back | 21% | 20% |

First clicks by element:

| Element | Layout A | Layout B |
|---|---|---|
| Tile: all postings | 17% | 29% |
| Chart | 25% | 17% |
| Tile: vs. a year ago | 21% | 19% |
| Tile: new postings | 18% | 19% |
| Tile: sectors above 2020 | 18% | 16% |

### Recommended next step

Roll out layout B, then confirm with a follow-up test that adds the page-speed and error guardrails this one lacked.
